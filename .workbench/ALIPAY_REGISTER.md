# 企业支付宝注册 + 支付宝接入明细流程（老板办理用）
# 2026-09-02 生成 · 配套 TASKS.md T-1788329411（支付宝接入）
# 目的: 支付宝用户也能走通 扫码H5->授权订阅->支付宝支付->原路退款,
#       分摊微信商户号封号风险, 微信不可用时支付宝兜底。
# 你有的: 营业执照。要办的: 企业支付宝账号 + 两个应用(网页应用=手机网站支付; 小程序应用=订阅消息)。

==========================================================
一、先理解要办几个"号"(大白话)
==========================================================
企业支付宝账号(1个) = 公司身份, 所有应用的"爹"。
  |-- 应用1: 网页应用 -> 开通[手机网站支付] -> H5拉起支付宝收银台(付押金)
  |-- 应用2: 小程序应用 -> 开通[消息/订阅消息] -> 支付宝小程序(授权取件/退款提醒)
每个应用 = 一套独立的 appid + 密钥, 别混。

==========================================================
二、第1步: 注册企业支付宝账号(3-7天, 含对公验证)
==========================================================
1. 打开 https://open.alipay.com -> 右上角[注册/登录]
2. 用营业执照注册[企业支付宝](或已有个人支付宝升级企业认证)
3. 企业认证材料(拍照上传, 要清晰完整):
   [ ] 营业执照 原件(或电子执照截图)
   [ ] 法人身份证 正反面
   [ ] 对公账户信息(用于打款验证: 支付宝打一笔小额, 你填金额确认)
   [ ] 或快速通道: 法人支付宝扫脸 + 执照上传(部分地区免对公打款, 以页面提示为准)
4. 认证通过 -> 得到企业支付宝账号(2088开头是用户ID, 不是应用ID)

==========================================================
三、第2步: 应用1 网页应用 -> 开通[手机网站支付](H5付押金用)
==========================================================
1. 企业支付宝登录开放平台 https://open.alipay.com
2. [控制台]->[创建应用]->[网页应用]
   应用名称: 科莱智寄存柜(或你定的名字)
3. 应用详情 ->[产品绑定]-> 添加产品 -> 搜并勾选:
   [ ] 手机网站支付(必须! alipay.trade.wap.pay, H5拉起收银台)
   (如需电脑网页付也顺带勾"电脑网站支付", 可选)
4. 等产品签约审核(一般1-3个工作日自动过)
5. [开发设置]->[接口加签方式]-> 支付宝官方[密钥工具]生成RSA2密钥对
   -> 把[应用公钥]填上去, 换回[支付宝公钥]
6. 记下并保密这3样(私钥绝不能外传, 配到服务器用):
   [ ] appid(应用ID, 如 2026xxxxxxxx)
   [ ] 应用私钥(自己生成保存)
   [ ] 支付宝公钥(支付宝页面显示)
7. [应用网关/回调地址]后端路由建好后填:
   https://locker.cqdyxl.com/api/pay/alipay/notify

==========================================================
四、第3步: 应用2 支付宝小程序 -> 订阅消息(提醒用)
==========================================================
1. 开放平台 ->[创建应用]->[小程序应用]
   小程序名称: 科莱智(和微信同名可以, 两套体系)
   类目: 生活服务/便民服务-智能寄存类(主营行业决定能领什么模板)
2. 绑定产品: 小程序 -> 权限集勾选[消息]
3. [开发设置]同样生成密钥, 记下 appid/应用私钥/支付宝公钥(独立于网页应用)
4. 提审: 上传代码后审核1-3天(现在只做1个订阅授权页, 内容少)
5. 审核通过后配订阅消息模板:
   商家平台 https://b.alipay.com -> 运营中心 -> 小程序 -> 消息/召回
   -> 接入订阅消息 -> 按行业选模板:
   [ ] 优先找[长期订阅]模板(一次授权可多次推送, 体验最好)
       搜关键词: 取件提醒/服务提醒/业务通知/存放提醒
   [ ] 找不到长期 -> 领[一次性订阅]模板(每单授权每单推, 和微信现在用法等价)
       退款到账提醒模板: 押金退回/退款提醒(领了备用, 实际退款支付宝官方也会通知)
6. 记录领到的模板ID(entityIds, 32位hex串), 连同密钥给我

==========================================================
五、第4步: 办完交给我这几样(进服务器配置)
==========================================================
网页应用(H5支付):
  [ ] appid
  [ ] 应用私钥(RSA2)
  [ ] 支付宝公钥
小程序应用(订阅消息):
  [ ] appid
  [ ] 应用私钥(RSA2)
  [ ] 支付宝公钥
  [ ] 订阅模板ID列表(长期/一次性都记下, 注明哪个是取件提醒、哪个是退款提醒)

==========================================================
六、要点/坑(大白话)
==========================================================
1. 微信小程序代码不能直接搬到支付宝小程序, 要重写(只需1个订阅授权页, 量小)
2. 订阅方案已定: 像微信一样以订阅通知为主(每单授权每单推), 短信没接好先不依赖
3. 支付走[手机网站支付](H5内拉起支付宝收银台), 不是小程序内付, 和微信一样在H5付
4. 柜机现有设备码是普通网页链接(store?cabinet_id=x), 支付宝内置浏览器能扫开, 一张码两边通用
5. 别用代码里现成的虎皮椒/xunhupay第三方通道(退款要人工后台, 押金模式会被投诉淹没)
6. 办完企业支付宝注册(应用1+应用2的appid/密钥), 后端alipay.py开发即可开工
