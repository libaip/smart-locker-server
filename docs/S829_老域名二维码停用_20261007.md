# S829 — 老域名二维码改为「已停用」页

- 日期：2026-10-07
- 编号：S829
- 关联：老板观察到"把后台生成的二维码发给不在现场的人扫 → 弹异常 → 该微信号之后连现场码也付不了"
  （即"异地扫码"被判异常）。要求：**老域名不再跳转新域名，扫进去直接显示"已停用"**。

## 一、改了什么

### 1) nginx（老域名 locker.cqdyxl.com）

改动文件：`/etc/nginx/sites-enabled/locker-cqdyxl`（HTTP + HTTPS 两处，均在 `location = /store`）

**改前**
```nginx
location = /store { return 302 https://kelaiwei.top$request_uri; }
```

**改后**
```nginx
location = /store {
    alias /home/ubuntu/smart-locker/static/qr_disabled.html;
    default_type text/html;
    add_header Cache-Control "no-store";
}
```

- **只改 `location = /store` 这一条**（`/retrieve` 保持原跳转，未动）
- **柜机 API（`/api/cabinets/by-mainboard/*`、`/api/pending-commands/*`、`/api/health`）一律未动**
- **支付/退款回调（`/api/pay/notify`、`/api/refund/notify`）未动**
- 备份：`/etc/nginx/sites-enabled/locker-cqdyxl.bak_s829_20261007_164901`

### 2) 新增静态页

`static/qr_disabled.html` —— 纯静态、无外链、无诱导关注内容（避免被微信拦）。
文案引导用户改用**柜机屏幕上显示的二维码**，避免现场贴纸失效导致用户流失。

## 二、部署与验证

| 项 | 结果 |
|---|---|
| 老域名 `/store?cabinet_id=24` | **200 + 停用页**（0 次跳转） |
| 老域名 `/store?device=100101` | **200 + 停用页** |
| 老域名裸 `/store` | **200 + 停用页**（不再被 Flask 追加 v 参数） |
| 连测 3 次 | 稳定 200 |
| 新域名 `/store?cabinet_id=24` | **200，正常流程，不含停用字样** |
| 老域名 `/retrieve` | 未动，仍 302 跳新域名 |
| 老域名 `/api/health` | 200 |
| 老域名 `/api/cabinets/by-mainboard/100101` | 200 |
| 老域名 `/api/pay/notify`（GET/POST） | 500 —— **新域名同样 500**，为应用对无签名请求的既有行为，与本次改动无关 |

文件 md5（106 与 175 一致）：`5bee4f8b86d449f8ba295ad9d7433778`

## 三、回滚方法

```bash
sudo cp /etc/nginx/sites-enabled/locker-cqdyxl.bak_s829_20261007_164901 \
        /etc/nginx/sites-enabled/locker-cqdyxl
sudo nginx -t && sudo systemctl reload nginx
```

## 四、注意

- nginx 有既有告警 `conflicting server name "locker.cqdyxl.com"`（存在重复 server 块，第二个被忽略），**非本次引入**。
- 现场若仍有老域名的旧贴纸，用户扫到会看到「已停用」页并被告知改扫柜机屏幕。
